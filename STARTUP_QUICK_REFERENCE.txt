⚙️ 关键配置文件

config.py:
    • LLM_PROVIDER = "deepseek"
    • LLM_MODEL = "deepseek-chat"
    • WORKSPACE_DIR = "workspace/" ← 生成代码位置
    • LLM_API_KEY = 从 .env 读取

.env:
    • LLM_API_KEY=sk-...        ← 填入你的 API Key
    • 受 .gitignore 保护
    • 不会被 Git 提交

Q: 如何启动？
A: ./cli.sh

Q: 生成的代码在哪？
A: workspace/ 目录

Q: 如何配置 API Key？
A: 编辑 .env 文件（从 .env.example 复制）

Q: 能否修改代码生成位置？
A: 编辑 config.py 中的 WORKSPACE_DIR

Q: 虚拟环境坏了怎么办？
A: 删除 .venv，重新运行 ./cli.sh

Q: 如何快速运行生成的代码？
A: cd workspace && python app.py
